# Mohamed Eisa — Portfolio Landing Page

Static one-page site (Architect | BIM Modeler). Ready for GitHub Pages.

## Deploy to GitHub Pages
1. Create a new GitHub repo (e.g. `mohamedeisa-portfolio`).
2. Upload all files in this folder (`index.html`, `style.css`, `script.js`, `assets/`) to the repo root.
3. Go to Settings → Pages → Source → select the `main` branch, `/ (root)` folder → Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Structure
- `index.html` — page content
- `style.css` — styling
- `script.js` — gallery lightbox + title-block interaction
- `assets/portfolio/` — pages from the portfolio PDF
- `assets/bim/` — Revit/BIM screenshots
